# Первый старт

Демонстрационный MVP платформы о спортивных школах Луганска, направлениях спорта и новых группах молодых тренеров.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`). Для проверки production-сборки: `npm run build`.

Публичный сайт: https://kuzyalove6-arch.github.io/pervy-start/ . Презентация для просмотра и демонстрации: https://kuzyalove6-arch.github.io/pervy-start/presentation.html . Для публикации соберите проект с `GITHUB_PAGES=true` (в PowerShell: `$env:GITHUB_PAGES='true'; npm.cmd run build`) и отправьте содержимое `dist` в ветку `gh-pages`. Рабочие документы, анкеты и первый вариант презентации не включаются в публичный репозиторий.

По умолчанию открывается вертикальная компоновка. Переключатель «Вид страницы» над первым экраном возвращает прежнюю широкую версию; прямой адрес прежней версии — `?layout=classic`. Выбор сохраняется в адресной строке, поэтому ссылкой на неё можно поделиться.

Материалы защиты проекта лежат рядом с сайтом: `Презентация_защита.html` (четыре слайда, стрелки клавиатуры и печать в PDF; доступна также по `/Презентация_защита.html` на локальном сервере), `Доклад_к_защите.md` и `ПРЕДЛОЖЕНИЯ_ПО_САЙТУ.md`. Презентация включена в production-сборку.

Альтернативная презентация в палитре `Референс.jfif` — `Презентация_защита_вариант_2.html`: пять слайдов с обзором сайта, иллюстрациями, кнопкой «Что сказать» с подсказками и печатью в PDF. В анкетах, приложенных к проекту, 13 ответов студентов и 7 ответов во второй группе; эти числа использованы в альтернативной презентации. Параметры пилота на её четвёртом слайде (1 начинающий тренер, 2 студента, 6 месяцев) — предлагаемый план, который нужно согласовать и отразить в рабочей тетради перед защитой.

## Что работает

- Календарь открытых тренировок с переходом по месяцам и подробностями по клику на дату: вид спорта, школа, возраст и уровень, время, место и тренер. Даты чередуются через две и три недели. Все события и параметры расписания — **демонстрационные примеры**, не подтверждённые объявления школ; фактические адреса площадок и имена тренеров пока неизвестны. Примеры настраиваются в `src/OpenTrainings.tsx`.
- Отдельные заметные плитки новых групп молодых тренеров.
- Небольшие презентации 13 видов спорта: короткий зацикленный фрагмент видео, где найден подходящий ролик Wikimedia Commons, и иллюстративный кадр при отсутствии или ошибке загрузки видео. Видео загружается только при открытии презентации; автор и лицензия указаны под роликом.
- 14 спортивных школ, центр олимпийской подготовки и училище олимпийского резерва из [таблицы администрации Луганска](https://gorod-lugansk.gosuslugi.ru/deyatelnost/napravleniya-deyatelnosti/fizicheskaya-kultura-i-sport/). Карточки содержат опубликованные название, юридический адрес, телефон и руководителя.
- Отдельная подборка пяти клубов и студий из [справочника Spravker](https://lugansk.spravker.ru/sportivnye-shkoly/) с прямыми ссылками на записи и явным предупреждением об ограничениях сведений. Их частный статус, работа с детьми и текущий набор справочником не подтверждены.
- Поиск по названию, адресу и указанному в названии направлению спорта. Для неуточнённых направлений фильтр совпадения не предполагает.
- Фотоиллюстрации в презентациях видов спорта. Это не фотографии школ. Изображения загружаются с Pexels и Wikimedia Commons; атрибуция для лицензируемого снимка указана в презентации.
- Демонстрационная форма записи.
- Демонстрационный кабинет спортшколы со списком заявок и изменением их статуса.

Школы из городского перечня существуют в опубликованной таблице, но она приводит **юридические адреса**, не обязательно места тренировок. Данные о возрасте приёма, требованиях, расписании и действующем наборе в ней отсутствуют; узнавайте их по опубликованным телефонам. Контакты из справочника Spravker могут быть устаревшими (в том числе номера +380). Карточки новых групп молодых тренеров — **отдельные демонстрационные примеры**, не объявления перечисленных организаций. Форма предназначена для тестовых данных: заявки сохраняются **только в localStorage текущего браузера** и не отправляются спортивным школам. Для публичной записи понадобятся подтверждённые объявления, серверное хранение, авторизация школ и доставка уведомлений.
